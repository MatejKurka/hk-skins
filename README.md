# Hollow Knight Multiplayer Skins (Custom Knight & HKMP)

Shared skins repository for **Custom Knight** and **HKMP**.

## Skin IDs (for HKMP)

| Skin Name | HKMP Skin ID (`id.txt`) |
| :--- | :--- |
| **Grub** | `1` |
| **Hornyt** | `2` |

## Setup Instructions

Clone or pull this repository into both:
1. `.../Hollow Knight/hollow_knight_Data/Managed/Mods/Custom Knight/Skins`
2. `.../Hollow Knight/hollow_knight_Data/Managed/Mods/HKMP/Skins`

In-game, open the **HKMP** menu (`Esc` -> right panel) and set your **Player skin ID** to the number from the table above.
